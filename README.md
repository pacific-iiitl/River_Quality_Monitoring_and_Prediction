# River_Quality_Monitoring_and_Prediction
This project is funded by CST-UP and has to be executed by December 2026....

O1: Develop a Continuous River Water  Monitoring system to keep track of pH levels, Dissolved Oxygen, and various necessary features  using sensors and a mobile/web application.
  1.	Literature Survey
  2.	Design the framework to track the pH levels, dissolved oxygen, and relevant parameters..
  3.	Find solutions to meet the sustainable goals of the framework during real-time monitoring and data analytics
     
O2: Build a robust and sustainable edge framework using data orchestration and a Machine Learning pipeline for efficient data management and a model for early and remote  monitoring of River Water parameters.

O3: Develop a feature fusion technique to extract features from different sources, including laboratory data (water samples to be collected from Ganga and Saryu Rivers) and real-time monitoring data at Ayodhya and Prayagraj, and to create a high-dimensional feature vector for representing different risks in river water.
